# Web-app-lab

นายธนภัทร สมบูรณ์ — รหัสนักศึกษา 663380347-5

Lab เว็บแอปพลิเคชันที่พัฒนาด้วย **Laravel (PHP)** อยู่ใน repository แยกของตัวเอง

## 🔗 https://github.com/tannysomb/Web-app-lab

---

| หัวข้อ | รายละเอียด |
|---|---|
| ภาษา / เฟรมเวิร์ก | PHP · Laravel |
| Front-end tooling | Vite, Tailwind CSS, PostCSS |
| การทดสอบ | PHPUnit (`phpunit.xml`) |
| โครงสร้างหลัก | `app/`, `bootstrap/`, `config/`, `database/`, `public/`, `resources/`, `routes/`, `storage/`, `tests/` |

เป็นโปรเจกต์ Laravel มาตรฐาน ไม่ได้โคลนเข้ามาใน repository นี้เพราะมี dependency
ของตัวเอง (`composer.json`, `package.json`) และมี repository แยกอยู่แล้ว
